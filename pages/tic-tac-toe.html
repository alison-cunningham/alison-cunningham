Tic-Tac-Toe Console Game

A console-based Tic-Tac-Toe game written in C#.

Players alternate placing X and O on a 3x3 game board until a player wins or the game ends in a tie. The game features:
  • Two player gameplay
  • Input validation
  • Win, tie detection, and score tracking
  • Game results written to a text file

What I learned:

Through this project I strengthened my understanding of 2D arrays, nested loops, method design, and input validation in C#.

I also gained experience working with game loop logic, win detection algorithms, StringBuilder objects, file writing using StreamWriter, and organizing larger programs into modular methods.
