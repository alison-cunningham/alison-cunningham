Payroll Simulator

This C# console application is a menu-driven program containing two main features: a Weekly Payroll Calculator and a Student Salary Estimator Based on Grades.

The program allows users to calculate employee payroll and generate and display simulated student records with estimated salaries based on academic performance.

Weekly Payroll Calculator

The payroll section calculates employee pay based on hours worked and hourly wage.

It supports:

  • Regular pay
  • Overtime Pay
  • Double overime pay
  • Input validation for invalid work hours
The program processes arrays of employee names, hours worked, and hourly rates, then generates a formatted payroll report for each employee.

Student Salary Estimator

The second section simulates student records by generating:

  • Validates user input
  • Generates randomized student grade data
  • Calculates salary based on performance tiers
  • Produces detailed summary reporting

I gained more experience working with arrays, loops, input validation, and methods while building a more robust console application. I also learned how to process calculations and format data clearly for the user.
