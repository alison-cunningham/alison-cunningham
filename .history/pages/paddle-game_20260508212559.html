Paddle Game

A fully interactive paddle arcade game developed in C# using real-time keyboard input.

Players control a paddle using the keyboard and compete against the computer to score points by sending the ball past the opponent’s paddle.

The game features:
  • AI-controlled opponent with multiple difficulty levels
  • Collision detection
  • Score tracking
  • Randomized gameplay modifiers that change the mechanics after each round
To make gameplay more dynamic and unpredictable, special game modes such as Ghost Ball, Fast Ball, Curve Ball, Drunk Paddle, and Small Paddle are randomly activated throughout the match.

What I learned:

This project introduced and strengthened my understanding of core game development concepts including game loops, object movement, simple AI behavior, collision handling, frame synchronization, and state management within a console application environment.
